# 📝 Day 3 – CI Pipeline Notes

## 1. What is CI?

CI stands for Continuous Integration.

It is a development practice where code changes are automatically checked whenever developers push code or create pull requests.

A CI pipeline can perform:

- Dependency installation
- Code quality checks
- Linting
- Unit testing
- Building
- Artifact generation
