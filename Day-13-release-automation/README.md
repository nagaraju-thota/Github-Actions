# Day 13 – Release Automation

## 🎯 Goal

Automate software releases using Git tags and GitHub Actions.

## 📚 Topics

- Git Tags
- Semantic Versioning
- GitHub Releases
- Release Notes
- Changelog Generation
- Release Artifacts

## 🛠️ Hands-on

This project demonstrates how to automatically create a GitHub Release when a version tag is pushed.

### Release Flow

```text
Code Changes
     ↓
Git Commit
     ↓
Create Version Tag
     ↓
Push Tag
     ↓
GitHub Actions
     ↓
Generate Changelog
     ↓
Create Release Artifact
     ↓
Create GitHub Release
